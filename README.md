# Java — Lógica de Programação e Orientação a Objetos

Exercícios em Java desenvolvidos no curso técnico, da lógica básica até orientação a objetos.

## Conteúdo

- **Listas 02 a 21:** entrada de dados com `Scanner`, operações, condicionais e laços
- **Cinema.java:** uso de arrays (filmes e classificações)
- **Lista24/:** classes e herança (animal, cachorro e gato; funcionário, gerente e vendedor; veículo e carro; produto, livro e filme)
- **POO/src/:** classes e objetos (Conta, Filme, Gato, Música, Pizza, Produto e Vídeo)

## Tecnologias

Java

## Como executar

```bash
javac Lista02.java
java Lista02
```

Troque `Lista02` pelo arquivo que quiser executar.
